# FleetPulse — Real-Time Fleet & Vehicle Telemetry Dashboard Backend

The complete backend implementation is located in the [`backend/`](./backend) directory.

### Quick Start:
```bash
cd backend
npm install
npm run seed
npm start
```

### Run Automated Verification Suite:
```bash
cd backend
npm run test:verify
```

### Documentation:
- Full API, Socket.IO, and architecture documentation can be found in [`backend/README.md`](./backend/README.md).
